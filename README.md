# 📋 Skypro Kanban Board

Веб-приложение для управления задачами в стиле Kanban доски с современным интерфейсом и полным функционалом.

## 🚀 Технологии

- **React 19** - современная библиотека для создания пользовательских интерфейсов
- **React Router DOM** - маршрутизация в SPA
- **Styled Components** - CSS-in-JS стилизация компонентов
- **Axios** - HTTP клиент для работы с API
- **React Toastify** - уведомления для пользователя
- **Vite** - быстрый сборщик и dev-сервер
- **ESLint** - линтер для контроля качества кода

## ⚡ Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Проверка кода линтером
npm run lint
```

## 🎯 Основные функции

### 🔐 Аутентификация и авторизация

- **Регистрация пользователей** - создание новых аккаунтов с валидацией данных
- **Авторизация** - вход в систему с проверкой учетных данных
- **Защищенные маршруты** - доступ к функциям только для авторизованных пользователей
- **Выход из системы** - безопасное завершение сессии
- **Сохранение сессии** - автоматическое сохранение состояния входа

### 📋 Управление задачами

#### Создание и редактирование

- **Создание новых задач** через модальное окно или отдельную страницу
- **Редактирование существующих задач** с возможностью изменения всех параметров
- **Удаление задач** с подтверждением действия
- **Валидация данных** при создании и редактировании

#### Структура задачи

- **Заголовок** - основное название задачи
- **Описание** - подробная информация о задаче
- **Дата** - срок выполнения с календарным выбором
- **Категория** - тип задачи (Web Design, Research, Copywriting)
- **Статус** - текущее состояние выполнения

### 🗂️ Канбан доска

#### Статусы задач

- **"Без статуса"** - только созданные задачи
- **"Нужно сделать"** - задачи в очереди на выполнение
- **"В работе"** - активно выполняемые задачи
- **"Тестирование"** - задачи на проверке
- **"Готово"** - завершенные задачи

#### Интерактивность

- **Drag & Drop** - перетаскивание задач между колонками для изменения статуса
- **Группировка по статусам** - автоматическое распределение по колонкам
- **Визуальные индикаторы** - цветовое кодирование по категориям
- **Адаптивный дизайн** - корректное отображение на всех устройствах

### 🔍 Поиск и фильтрация

#### Поиск

- **Поиск по заголовку** - быстрый поиск задач по названию
- **Реальное время** - мгновенная фильтрация при вводе
- **Подсветка результатов** - визуальное выделение найденных элементов

#### Фильтрация

- **По категориям** - отображение задач определенного типа
- **По статусам** - фильтрация по состоянию выполнения
- **Комбинированные фильтры** - совместное использование поиска и фильтров

#### Сортировка

- **По названию** - алфавитная сортировка (А-Я)
- **По дате** - хронологическая сортировка (новые сначала)
- **По категории** - группировка по типу задач

### 📊 Статистическая панель

#### Общая статистика

- **Общее количество задач** - всего задач в системе
- **Процент выполнения** - соотношение готовых к общему количеству
- **Прогресс-бар** - визуальное отображение процента выполнения
- **Счетчики по статусам** - количество задач в каждом статусе

#### Анализ просроченных задач

- **Автоматическое определение** - задачи с истекшим сроком
- **Список просроченных** - топ-5 самых критичных задач
- **Общий счетчик** - общее количество просроченных задач
- **Исключение завершенных** - готовые задачи не считаются просроченными

#### Статистика по категориям

- **Распределение по типам** - количество задач каждой категории
- **Цветовые индикаторы** - визуальное различение категорий
- **Динамическое обновление** - автоматический пересчет при изменениях

### 🎨 Персонализация

#### Темизация

- **Светлая тема** - классический дневной режим
- **Темная тема** - комфортный ночной режим

- **Сохранение предпочтений** - запоминание выбранной темы

#### Настройки интерфейса

- **Скрытие/показ статистики** - возможность отключения панели аналитики

- **Адаптивные элементы** - изменение интерфейса под размер экрана

### 📱 Уведомления

#### Типы уведомлений

- **Успешные операции** - подтверждение выполненных действий
- **Ошибки валидации** - предупреждения о некорректных данных
- **Системные ошибки** - информация о технических проблемах
- **Информационные** - дополнительная полезная информация

- **Автоматическое скрытие** - исчезновение через заданное время

## 🌐 API интеграция

### Аутентификация

- `POST /api/auth/register` - регистрация пользователя
- `POST /api/auth/login` - авторизация пользователя

### Управление задачами

- `GET /api/kanban` - получение всех задач пользователя
- `POST /api/kanban` - создание новой задачи
- `GET /api/kanban/:id` - получение задачи по ID
- `PUT /api/kanban/:id` - обновление задачи
- `DELETE /api/kanban/:id` - удаление задачи
